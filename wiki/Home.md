# Wiki Python

Bienvenue dans la documentation du projet **Python**. Le README présente le projet en quelques lignes ; ce wiki développe les notions et les procédures.

## Parcours conseillé

1. [Présentation de Python](Presentation-de-Python.md) — histoire, caractéristiques et règles de syntaxe.
2. [Installation et premier programme](Installation-et-premier-programme.md) — préparer l'environnement et exécuter un premier fichier.
3. [Python et cybersécurité](Python-et-cybersecurite.md) — découvrir quelques usages et bibliothèques.
4. [IDE et outils](IDE-et-outils.md) — comprendre le rôle de VS Code et des extensions.

## À retenir

- Python est un langage polyvalent et lisible.
- L'indentation délimite les blocs de code.
- Python utilise un typage dynamique.
- VS Code est l'éditeur choisi pour ce projet.
- Hello World permet de vérifier que l'environnement fonctionne.
