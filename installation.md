# Installation de l'environnement Python

## 1. Installation de Python

J'ai commencé par installer Python sur mon ordinateur.

Après l'installation, j'ai vérifié que Python fonctionnait correctement
avec la commande :

```bash
python --version
```

Cette commande permet d'afficher la version de Python installée.

---

## 2. Installation de Visual Studio Code

J'ai choisi **Visual Studio Code (VS Code)** comme IDE.

Après avoir installé VS Code, j'ai ouvert le logiciel.

Je suis ensuite allé dans l'onglet **Extensions** et j'ai recherché :

```text
Python
```

J'ai installé l'extension **Python** publiée par Microsoft.

Cette extension permet notamment :

- d'exécuter des programmes Python ;
- d'avoir de l'autocomplétion ;
- de détecter certaines erreurs ;
- de déboguer les programmes.

---

## 3. Création du programme Hello World

J'ai créé un dossier nommé :

```text
hello_world
```

Puis un fichier nommé :

```text
hello.py
```

J'ai écrit le programme suivant :

```python
print("Hello World")
```

---

## 4. Exécution du programme

J'ai ouvert le terminal dans VS Code.

J'ai ensuite exécuté :

```bash
python hello.py
```

Le résultat obtenu est :

```text
Hello World
```

Le programme fonctionne correctement.

---

## 5. Vérification de l'environnement

Le programme Hello World permet de vérifier :

- que Python est installé ;
- que VS Code fonctionne ;
- que l'extension Python est installée ;
- que le programme peut être exécuté ;
- que le terminal fonctionne correctement.

Mon environnement de développement Python est donc fonctionnel.
