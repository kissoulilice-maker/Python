# Python

Ce dépôt présente le langage **Python**, ses principales caractéristiques et la mise en place d'un environnement de développement avec **Visual Studio Code (VS Code)**.

## En bref

Créé par **Guido van Rossum** et publié en 1991, Python est un langage lisible et polyvalent. Il est utilisé dans le développement, l'automatisation, l'analyse de données, les réseaux et la cybersécurité.

## Exemple rapide

~~~python
print("Hello World")
~~~

Exécution depuis le terminal :

~~~bash
python hello.py
~~~

Résultat attendu :

~~~text
Hello World
~~~

## Objectif

Ce dépôt sert de support d'apprentissage pour découvrir Python, comprendre ses bases et préparer un environnement de développement fonctionnel.
